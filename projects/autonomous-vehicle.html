Autonomous Vehicle Drive

Type
Project
Area
Robotics, Deep Learning
Code
GitHub

A vehicle designed from scratch and driven autonomously using a multilayer perceptron, with live video streamed from an on-board camera.

Tech used

  • Multilayer perceptron (MLP)
  • Sockets for live video streaming
  • Microcontrollers — Arduino (transmitter and receiver)
  • RF communication — nRF24L01+ for wireless control
  • On-board compute — Raspberry Pi 3 with camera
