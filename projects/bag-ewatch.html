Bag eWatch

Type
Project
Area
Hardware, Embedded
Code
GitHub

A 200×200 e-ink paper display attached to a bag as a badge, showing time along with altitude, pressure and humidity readings.

Tech used

  • NodeMCU
  • E-ink display — 200×200, 5.4 inch
  • Sensors — BMP180, DHT11
  • Libraries — ESP8266WiFi, U8g2lib, Wire, Adafruit_BMP085, Geometry, SPI
